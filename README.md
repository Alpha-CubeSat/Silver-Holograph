# Silver-Holograph
domain: https://www.cornellsailingtothestars.com/

## Description
This project is a static website for the Silver-Holograph team, featuring pages for outreach, timeline, ISS, team, and more. It includes HTML, CSS, and image assets, as well as a Unity WebGL build.

## Prerequisites
- A modern web browser (Chrome, Firefox, Edge, Safari)
- (Optional) Python 3 for running a local server

## Running the Project

### Option 1: Open Directly
Open `index.html` in your web browser to view the site.

### Option 2: Run a Local Server (Recommended)
Some browsers restrict loading local files. To avoid issues, run a simple local server:

**Using Python 3:**
```bash
python3 -m http.server 8000
```
Then open [http://localhost:8000](http://localhost:8000) in your browser.

## Project Structure
- `index.html`, `timeline.html`, `iss.html`, etc.: Main site pages
- `styles/`: CSS stylesheets
- `images/`: Image assets
- `Build/`: Unity WebGL build files
